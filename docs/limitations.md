# Supported release scope

OpenAI is **optional**. No key is required to start the application, create an account, manage projects or teams, extract evidence, calculate impacts, author and review professional findings, compare versions, reopen analysis, export PDFs, or download complete project archives. Users can add an encrypted organization key later in Settings. The application never seeds fictitious AI conclusions or labels unexecuted AI work complete.

The intended launch is a **single-instance construction evidence and professional-assessment workspace**. It has been exercised locally and in a non-root container. This is not a guarantee of perfection, model accuracy, legal sufficiency, or performance on an untested hosting service.

## AI validation deferred by choice

Real Responses API integration, specialist tool loops, structured outputs, source verification, bounded retries, token accounting and cancellation are implemented. Live OpenAI requests, model-driven contradiction quality, and the complete autonomous before/after demonstration are **unrun** because the key is intentionally empty. Transport-mocked tests establish application behavior around the provider; they do not prove model behavior. Run a real-key acceptance case before offering autonomous AI investigations as a validated service. The withheld fictional email in `withheld-access-email.eml` is ordinary evidence, never a special trigger.

## Product boundaries

- Local OCR currently uses the bundled **English** language model. OCR may misread text. Original files remain available, with extraction method and confidence shown. PDFs are limited to 500 pages and 20 scanned pages; files to 15 MB; image inputs to 20 megapixels; extracted text to 2 million characters per document and 5 million per project. Oversized or unreadable inputs fail explicitly.
- PDF/TXT/EML/CSV/JSON and PNG/JPEG/WebP are supported. MIME email bodies are decoded; attachment metadata is listed, but attachments must be uploaded separately. Proprietary schedule formats and XLSX are not supported. CSV/JSON imports use the documented schemas and require an explicit import action.
- Scheduling uses finish-to-start dependencies and calendar-day offsets, with an optional baseline date. It does not implement resource leveling, working-day calendars or industry forensic delay methodologies. A modeled delay is not legal entitlement.
- Incremental invalidation uses explicit source references, evidence topics/categories and dependency closure. Unknown text conservatively invalidates analytical nodes. It is not a semantic truth oracle: professionals can explicitly reopen additional nodes. Model-generated contradiction conclusions still require live validation and human review.
- Source checking establishes that quoted text exists on a specific page. It does not prove factual correctness, interpretive accuracy or legal sufficiency. Professional findings are labeled human-authored, and review is explicit. Users may review their own assessment; there is no enforced four-eyes policy.
- Accounts support password rotation, single-use offline recovery codes, expiring team invitations, role changes, member removal and session revocation. Invitation delivery is a secure-link workflow; the app sends no email. MFA, SSO and multiple organizations per email are outside this release.
- SQLite stores project aggregates and durable job records. Background investigations resume valid unfinished work after restart. Extraction has a bounded subprocess queue and explicit timeout; an interrupted upload must be retried. Multi-instance deployment is unsupported. Use one persistent service, not an ephemeral or horizontally scaled serverless deployment.
- Original files have restrictive filesystem permissions; organization API keys are encrypted with AES-256-GCM. Use HTTPS, a protected persistent volume, and an encrypted backup destination appropriate to your records. Local key storage does not defend against a compromised host. This task does not certify regulatory compliance, malware scanning, disaster operations or independent penetration testing.
- Container and local stress results describe the tested small fictional workload. They do not establish live-model, WAN, prolonged, maximum-document or multi-tenant production capacity. Token-based dollar estimates require entered provider rates; provider invoices remain authoritative.
